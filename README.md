# kalemin-yazmamasi-icin-karalama-yapma-zorunlulugu-milli-egitim-bakanligi
Kalemin yazmadan önce karalama kâğıdı istemesini resmi eğitim krizi, milli mürekkep egemenliği ihlali ve imza protokolü sapması sayan; kapağı müdür, 'biraz karalarım gelir' cümlesini sınav kaçağı ilan eden Bakanlık. Gerçekten çalışır. Kalemler artık öğrencidir.
